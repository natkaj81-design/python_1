# Python з нуля — комікси та вправи

Статичний навчальний сайт українською мовою. Містить головну сторінку, чотири навчальні комікси та сторінку «Вправи».

## Вправи

П'ять незалежних варіантів, у кожному три вправи по 12 завдань:
1. «Так або ні» — визначення правильності імен змінних і констант (6 правильних і 6 неправильних).
2. «Тест» — 12 запитань з однією або кількома правильними відповідями.
3. «Правда чи неправда» — 12 тверджень (6 істинних і 6 хибних).

Оцінка: один бал за повністю правильне завдання, максимум 12. У тесті з кількома відповідями бал нараховується лише за повний правильний набір. Після перевірки доступні пояснення й повторне проходження. Результати зберігаються лише під час відкритого сеансу сторінки.

## GitHub Pages

Розпакуйте архів. Завантажте **всі** файли та папку `assets` до кореня репозиторію. У GitHub відкрийте Settings → Pages → Deploy from a branch → main → /(root) → Save.

Для локального використання відкрийте `index.html` **після розпакування** архіву.
