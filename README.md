# Python з нуля — сайт і надсилання результатів

Сайт має 4 навчальні комікси, сторінку «Вправи», 5 варіантів по 3 вправи (по 12 завдань). У назві вкладки браузера — «Python з нуля».

## Публікація сайту на GitHub Pages

Розпакуйте ZIP і завантажте `index.html`, `style.css`, `script.js`, `exercises.js`, `exercises-data.js`, `config.js` і папку `assets` у корінь репозиторію. Файл `Code.gs` на GitHub не потрібний: його код вставляється в Google Apps Script. У GitHub відкрийте Settings → Pages → Deploy from a branch → main → /(root) → Save.

## Налаштування Google Таблиці та Gmail

1. Створіть **нову приватну Google Таблицю** для результатів.
2. Відкрийте **Розширення → Apps Script**.
3. Вставте в редактор весь код із файлу `Code.gs`. Адресу одержувача `natkaj81@gmail.com` уже внесено до `Code.gs`.
4. Виберіть **Deploy → New deployment → Web app** (Розгорнути → Нове розгортання → Вебзастосунок). `Execute as`: **Me** (Від мого імені); `Who has access`: **Anyone** (Усі), якщо учні не мають входити в Google. Надайте дозволи на Таблиці та надсилання пошти. Зважайте, що такий публічний endpoint може отримувати підроблені запити — це не система захищеного оцінювання.
5. **URL вебзастосунку вже додано до `config.js`.** Повторно вставляти його не потрібно.
6. Завантажте всі файли оновленого сайту на GitHub. Перевірте на тестовому учневі: усі 3 вправи → кнопка надсилання → перевірка рядка в Google Таблиці та листа Gmail.

**Важливо:** без кроків 1–5 сайт працюватиме, але результати **не надсилатимуться**. Через обмеження браузера запит надсилається без читання відповіді сервера, тому повідомлення «запит відправлено» не гарантує, що запис відбувся. Перевіряйте надходження у Таблицю. Apps Script має квоти на надсилання листів.

## Які дані зберігаються

Ім'я та клас, варіант, оцінки за 3 вправи, середня оцінка, дата/час отримання та лічильники спроб. Лічильник спроб ведеться **в браузері учня** (localStorage) окремо для введеного імені, класу, варіанта і вправи. Учень може очистити дані браузера або змінити ім'я, тож це не захищений від маніпуляцій підрахунок спроб. Результати передаються лише після натискання кнопки «Завершити та надіслати результат». Учням потрібно повідомити, які персональні дані збираються, і обмежити доступ до Таблиці.
